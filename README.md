# КиберЩит

Учебный сайт «Чат-бот по изучению компьютерных вирусов. Профилактика и защита».

Для запуска сервера нужен Node.js 24 или новее. Сторонние пакеты не нужны.

```powershell
node server.js
```

Откройте http://localhost:3000. Посетителям нужен только браузер. Для демонстрации на телефоне в доверенной локальной сети запустите сервер с `$env:HOST="0.0.0.0"` и откройте на телефоне адрес компьютера с портом 3000. Подключение может зависеть от настроек брандмауэра.

Результаты записываются в SQLite (`data/results.sqlite`). Страница статистики показывает общие результаты всех попыток на данном экземпляре сайта. Чат отвечает по встроенной базе материалов и работает без внешнего ИИ и ключей.

Команда `node --test` проверяет страницы, ответы бота, подсчёт баллов и сохранение результатов при перезапуске.

## GitHub Pages

Команда `node build-pages.js` готовит статическую версию в `dist/pages`. Содержимое этой папки публикуется из корня ветки `gh-pages`.

В опубликованной версии тест подсчитывает баллы в браузере. История хранится в локальном хранилище браузера и остаётся после перезагрузки страницы. Очистка данных сайта удаляет эту историю. У разных браузеров и устройств свои результаты.
